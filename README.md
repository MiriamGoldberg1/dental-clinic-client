# מרפאת שיניים - לקוח React

לקוח שמדגים את כל הפונקציות של שרת ה-API. התפריט משתנה לפי התפקיד (ההרשאה האמיתית נבדקת בשרת).

**לכולם**
- **התחברות והרשמה** - ה-JWT נשמר ונשלח ב-header בשם `Authorization` בכל בקשה.
- **קביעת תור** - בחירת רופא, תאריך ושעה פנויה; הצגת 409 כשהשעה נתפסה, וכפתור "הדגמה: שתי בקשות בו-זמנית" (אחת מקבלת 201 והשנייה 409).
- **רופאים** - רשימה עם דפדוף אמיתי מול השרת, חיפוש, סינון לפי התמחות, מיון, ופרטי רופא.
- **תורים** - רשימה עם דפדוף, סינון (רופא, סוג טיפול, טווח תאריכים) ומיון; פרטי תור; ביטול תור.

**מטופל**
- **התורים שלי** - רק התורים של המטופל.
- **הפרטים שלי** - פרטים אישיים, History, כל התורים שקבע, ועדכון הפרטים.

**מנהל**
- **כל התורים** - כולל סינון לפי מטופל, וקביעת תור לכל מטופל.
- **מטופלים** - רשימה עם דפדוף, חיפוש ומיון; פרטי מטופל עם History ותורים; הוספה ועריכה.
- **רופאים** - בנוסף: הוספת רופא ועריכת רופא, כולל בחירת התמחויות.

## הרצה

דרישות: Node.js 18 ומעלה, ושרת ה-API רץ על http://localhost:5001 (ניתן לשנות בקובץ `.env`).

```bash
npm install
npm run dev
```

ואז לפתוח http://localhost:5173

משתמשי דמו: `admin@clinic.local` / `Admin123!`, `patient@clinic.local` / `Patient123!`
